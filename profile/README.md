# OpenE2EE

**End-to-end encryption SDKs for TypeScript developers.**

OpenE2EE builds open-source, protocol-level E2EE packages that run where JavaScript apps actually run: Expo and React Native, modern browsers, and Node — pure TypeScript, no native modules, no prebuild step.

## Products

- **[Signal Protocol SDK](https://github.com/open-e2ee/signal-protocol-js)** (`@open-e2ee/signal-protocol-sdk`) — an independent TypeScript implementation of a versioned messaging profile based on the public [Signal Protocol specifications](https://signal.org/docs/): post-quantum PQXDH + Double Ratchet, multi-device, groups, sealed sender, encrypted attachments, safety numbers, and pluggable storage/relay/object-store adapters. Currently `0.1.0-alpha`.
